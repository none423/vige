## 1. 项目概述

### 1.1 系统目标
开发一套完整的**财务代理记账系统**，实现：
- 多客户账套管理
- 会计凭证全流程管理
- 发票识别与归档
- 自动生成财务报表
- 银行对账自动化
- 税务申报辅助
- 客户自助查询门户（Web + 微信H5）

### 1.2 系统角色

| 角色 | 说明 | 权限范围 |
|------|------|---------|
| 系统管理员 | 系统运维 | 全局配置、账户管理 |
| 会计主管 | 审核监督 | 凭证审核、报表审批 |
| 记账会计 | 日常记账 | 凭证录入、发票处理 |
| 客户经理 | 客户服务 | 客户沟通、资料收集 |
| 客户 | 被代理企业 | 查看报表、提交票据 |

### 1.3 技术栈

**继承 Vige 现有技术栈**：
- 后端：FastAPI + SQLAlchemy 2.0 + PostgreSQL
- 前端：Vue 2 + iView
- 微信端：Vue 2 + Mint UI
- 缓存：Redis
- 任务队列：Huey

```python
class Voucher(CRUDMixin, TrackableMixin):
    """记账凭证"""
    
    account_set_id: int           # 所属账套
    customer_id: int             # 所属客户
    
    # 凭证号
    voucher_no: str              # 凭证号（按期间+顺序）
    period: str                  # 会计期间 (YYYY-MM)
    
    # 凭证信息
    voucher_date: date           # 凭证日期
    attach_count: int            # 附件张数
    source_type: str             # 来源（手工/自动/结转）
    source_id: int               # 来源ID（关联发票、银行对账等）
    
    # 审核流程
    status: str                  # 状态（待录入/待审核/已审核/已过账）
    preparer_id: int             # 编制人
    reviewer_id: int             # 审核人
    poster_id: int               # 过账人
    prepared_at: datetime        # 编制时间
    reviewed_at: datetime        # 审核时间
    posted_at: datetime          # 过账时间
    
    # 内容
    summary: str                 # 凭证摘要
    entries: List[VoucherEntry] # 分录（关系）
    
    @property total_debit()      # 借方合计
    @property total_credit()     # 贷方合计
    @property is_balanced()      # 是否平衡
```

```vue
          </Col>

            <FormItem label="附件张数">

            </FormItem>
          </Col>
        </Row>
        <FormItem label="摘要">
          <Input v-model="voucher.summary" placeholder="凭证摘要" />
        </FormItem>
      </Form>
      
      <!-- 凭证分录表格 -->
      <Table :columns="entryColumns" :data="voucher.entries" border>
        <template slot-scope="{ row, index }" slot="account">
          <Select v-model="row.account_id" filterable>
            <Option v-for="acc in accountTree" :value="acc.id" :key="acc.id">
              {{ acc.code }} - {{ acc.name }}
            </Option>
          </Select>
        </template>
        <template slot-scope="{ row, index }" slot="debit">
          <InputNumber 
            v-model="row.debit_amount" 
            :formatter="value => `${value}`"
            :parser="value => value.replace(/^\$|/g, '')"
            @on-change="calculateTotal"
          />
        </template>
        <template slot-scope="{ row, index }" slot="credit">
          <InputNumber v-model="row.credit_amount" />
        </template>
        <template slot-scope="{ row, index }" slot="action">
          <Button type="error" size="small" @click="removeEntry(index)">
            删除
          </Button>
        </template>
      </Table>
      
      <!-- 添加分录按钮 -->
      <Button type="dashed" long @click="addEntry" icon="md-add">
        添加分录
      </Button>
      
      <!-- 合计显示 -->
      <div class="total-row">
        <span>借方合计：{{ totalDebit }}</span>
        <span>贷方合计：{{ totalCredit }}</span>
        <span :class="{ 'balance-error': !isBalanced }">
          {{ isBalanced ? '平衡 ✓' : '不平衡 ✗' }}
        </span>
      </div>
      
      <!-- 操作按钮 -->
      <div class="form-footer">
        <Button @click="saveDraft">保存草稿</Button>
        <Button type="primary" @click="submitVoucher">提交</Button>
      </div>
    </Card>
  </div>

<script>
export default {
  data() {
    return {
      voucher: {
        voucher_date: new Date(),
        attach_count: 0,
        summary: '',
        entries: [
          { account_id: null, debit_amount: 0, credit_amount: 0, summary: '' },
          { account_id: null, debit_amount: 0, credit_amount: 0, summary: '' }
        ]
      },
      entryColumns: [
        { title: '科目', slot: 'account', minWidth: 200 },
        { title: '借方金额', slot: 'debit', width: 150 },
        { title: '贷方金额', slot: 'credit', width: 150 },
        { title: '摘要', key: 'summary', minWidth: 150 },
        { title: '操作', slot: 'action', width: 80 }
      ]
    }
  },
  computed: {
    totalDebit() {
      return this.voucher.entries.reduce((sum, e) => sum + (e.debit_amount || 0), 0)
    },
    totalCredit() {
      return this.voucher.entries.reduce((sum, e) => sum + (e.credit_amount || 0), 0)
    },
    isBalanced() {
      return Math.abs(this.totalDebit - this.totalCredit) < 0.01
    }
  },
  methods: {
    addEntry() {
      this.voucher.entries.push({
        account_id: null,
        debit_amount: 0,
        credit_amount: 0,
        summary: ''
      })
    },
    removeEntry(index) {
      this.voucher.entries.splice(index, 1)
    },
    async submitVoucher() {
      if (!this.isBalanced) {
        this.$Message.error('借贷不平衡，请检查')
        return
      }
      // 调用 API 提交凭证
    }
  }
}
</script>
```

## 7. 开发规范

### 7.1 后端开发规范

#### 目录结构
每个模块遵循以下结构：
```
vige-api/vige/api/{module}/
├── __init__.py
├── api.py          # API 路由定义
├── models.py       # 数据模型
├── forms.py        # Pydantic 表单验证
├── schemas.py      # 响应数据结构（可选）
├── tasks.py        # Huey 异步任务（可选）
└── constants.py    # 模块常量（可选）
```

#### 模型定义规范
```python
from ...db import Base, CRUDMixin, ProfileMixin, TrackableMixin

class YourModel(CRUDMixin, ProfileMixin, TrackableMixin):
    __tablename__ = 'your_table_name'
    
    # 使用 Mapped 类型注解
    name: Mapped[str] = mapped_column(String(100), nullable=False)
    code: Mapped[str] = mapped_column(String(50), unique=True)
    
    # 必须实现 dump 方法
    def dump(self):
        return {
            'id': self.id,
            'name': self.name,
            'code': self.code,
        }
```

#### API 路由规范
```python
from fastapi import Depends, HTTPException
from sqlalchemy.orm import Session
from ...db import sm
from ..decorators import perm_accepted
from ..constants import AccountingPermission
from .forms import YourForm
from .models import YourModel

@router.post('/module/items')
@perm_accepted(AccountingPermission.module_manage)  # 权限控制
def create_item(
    form: YourForm = Depends(),
    db: Session = Depends(sm.get_db)
):
    with sm.transaction_scope() as ts:
        item = YourModel.create(ts, **form.dict())
        result = item.dump()
    return dict(success=True, item=result)
```
